# Rastgele Türk Filmi Diyalog Üreticisi

## Bu Ne Lan?

Bu repository, Türkiye'nin en büyük sorunu olan "gerçekçi Türk filmi diyaloglarının yokluğu" sorununu çözmek için yaratılmıştır. 

**Ciddi uyarı:** Bu kod çalışır. Gerçekten çalışır. Ama ürettiği diyaloglar o kadar absürt ki, Yeşilçam bile kıskanır.

### Nasıl Kullanılır?

```bash
python diyalog_uretici.py
```

Çıktı örneği:
- Komşu Teyze çayı döktü: 'Benim oğlum doktor olacak, senin oğlun ne olacak?'

### Özellikler

- %100 Türkçe
- %0 mantık
- %200 abartı
- Gerçekçi değil ama komik

### Neden Var?

Çünkü birileri "durduk yere repo aç" dedi. Biz de açtık. Anlamlı olması gerekmiyordu.
